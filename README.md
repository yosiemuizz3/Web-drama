# 🎬 DRACIN HUB

**Nonton Drama China Short Subtitle Indonesia Gratis**

DRACIN HUB adalah web app untuk nonton drama china short. Data real-time dari Short Drama Pro API. Tampilan mirip Netflix, ringan, dan bisa dibungkus jadi APK Android.

![Preview](https://via.placeholder.com/1200x600/0f0f0f/e50914?text=DRACIN+HUB)

## ✨ Fitur
- 🔍 **Search + Auto Suggest** - Cari drama langsung ada saran judul
- 📂 **Filter Genre** - Romantis, Historis, Fantasi, Modern
- 📺 **Detail + Daftar Episode** - Klik langsung lihat semua episode
- 📱 **Responsive** - Mobile first, enak di HP
- ⚡ **Data Real-time** - Ngambil dari API Short Drama Pro
- 🚀 **Bisa Jadi APK** - Tinggal build pakai Capacitor

## 🛠️ Tech Stack
`HTML5` `CSS3` `Vanilla JavaScript` `RapidAPI`
